# Tasks done in lab 1

1. **Load & visualize images** – read an image with OpenCV (`cv2.imread`) and with PIL (`Image.open`), display both using Matplotlib.
2. **Save images** – write images to disk using `cv2.imwrite` and `img.save` (PIL).
3. **Display image as array** – inspect the OpenCV and PIL images as NumPy arrays (`shape`, raw values).
4. **NumPy arithmetic operations** – addition, subtraction, multiplication, and division between two image arrays, with results visualized.
